# DreamMargin client

Interactive product preview for the DreamMargin application. The interface is
implemented with React, TypeScript, and Vite and follows the DreamMargin brand
system supplied with the project.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` for a production build
and `npm run typecheck` for a TypeScript-only check.

All market, wallet, and position values are illustrative. This preview does not
connect to contracts or submit transactions.
